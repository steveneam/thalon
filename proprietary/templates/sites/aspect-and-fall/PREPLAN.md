## Draw

- Vertical: **garden & landscape design studio** (my recommendation under his
  *"and etc."*; one word to overrule, and he has now had two sessions' notice
  on the NEEDS-STEVEN board that this is the one about to spend)
- Business: **Aspect & Fall** — the two facts every landscape design begins
  from and neither of which is a matter of taste: which way the site faces
  (aspect), and which way the water goes (fall). **The name earns its own
  section**, which is the Whitethorn precedent that worked: the studio is
  named after the survey, so the survey sheet explains the name. It carries a
  quiet second reading too — *fall* is also the season the page passes
  through, and the page never points at the pun.
- Primary axis: **otherworldly-animation** (the scroll clock)
- Secondary axis: **editorial-print**
- **Pair is portfolio-new — verified against all 21 `site.json` files.**
  `northpace` holds otherworldly+novel-typography, `orchard-house`
  otherworldly+cinematic, `whitethorn` otherworldly+data-instrument.
  Nothing holds **otherworldly+editorial-print**, and editorial-print is the
  honest pair here because a landscape studio's actual deliverable is a
  **numbered set of drawing sheets** — title block, scale bar, north arrow,
  plant schedule, revision list. The page is built as that set.
- Palette seed: **drafting paper** (warm off-white), **graphite** (a warm
  near-black, never pure black), and **non-photo blue** for the setting-out
  grid — the real drafting-pencil blue that deliberately does not reproduce.
  **The one colour rule, stated so it can be checked: the only saturated
  colour on the page belongs to PLANTS, and it changes with the month.**
  Nothing decorative is ever coloured. This is honest to the discipline — on
  a real plan the colour *is* the planting — and it is why the palette cannot
  be confused with `orchard-house`'s four painterly season worlds.
- Type: **Spectral** (roman + italic — italic carries the Latin binomials, as
  horticultural print has always set them) + **Sometype Mono** (every piece of
  sheet apparatus: labels, dimensions, readouts, the title block). **Two
  families, not three** — a real drawing sheet has exactly two lettering
  registers, so the restraint is the discipline's, not mine. Both OFL, both
  vendored, both **portfolio-new** (verified against the ~40 faces already
  vendored across the other 21 sites).
- Motion budget: **one scroll clock — the calendar year.** No second animation
  system. The maturity chapter (year 1/3/10) is three static states, not a
  second clock.

## Look-first taste notes (Dribbble ×2 · motionsites.ai · Pinterest)

1. **The category default is a photo mosaic in a white shell.** Dribbble's
   "landscape architecture website" returns page after page of the same
   layout — a grid of site photographs, thin sans, one orange accent, an
   `About Us / Our Legacy / Our Team` spine. It sells the *studio*. **Refused
   by name.** This page sells the *drawing*, and photographs appear only where
   they are evidence.
2. **The adjacent default is worse: the mint-green plant app.** "Planting plan
   garden design" returns almost entirely mobile plant-care UI — rounded
   cards, mint/emerald gradients, leaf icons. Nothing about a professional
   design practice looks like that. **Refused.**
3. **motionsites.ai, read double-edged as the meta-prompt instructs.** Its own
   gallery is the current AI-landing default it warns about: near-black
   ground, glowing gradient headline, neon 3D. The strongest available refusal
   for this site is the exact opposite and it costs nothing — **paper, at full
   brightness.** Distinctness falls out of the register choice.
4. **The real artefact, from Pinterest: the canopy circle is this
   discipline's atom.** Overlapping circles of differing radius, scalloped or
   hatched edges, leader lines out to letterspaced caps labels, a hatched
   path, a plant key band along the bottom. **The principle to steal: the
   circle's RADIUS carries the information** — it is mature spread. So growing
   the radius over time is not decoration, it is the drawing's own native way
   of saying *"in ten years"*. That is the maturity chapter, in the
   discipline's grammar rather than in mine.
5. **Two registers coexist inside the discipline** — pure graphite linework
   plans, and the same plans rendered in coloured pencil. **Principle: let the
   linework stay graphite and let COLOUR be the thing the clock adds.** A full
   season story with no second palette system.

### The schematic test, applied before drawing anything

Site A cost three build rounds learning this, so it gets applied first here.

- **A naturalistic tree drawn in SVG: FAILS.** It is a picture of a thing. The
  banked idea was literally "one tree through four seasons" and drawing that
  tree is precisely the trap ⑳ fell into. **Not built.**
- **A plan-view planting drawing — canopy circles, hatch, leader lines, plant
  key, north arrow: PASSES, unambiguously.** It is the single most common
  drawing a landscape practice produces; the Pinterest sweep is wall-to-wall
  evidence. Drawn in code it reads as expertise.
- **A seasonal interest calendar (species × months): PASSES.** A real, named
  deliverable, and the one that makes "we design for October" checkable
  instead of claimed.
- **A survey drawing — contours, spot levels, fall arrow, sun path: PASSES.**
- **A photograph of an actual garden: MINT.** Per the founder's standing
  split, *photographs carry the feeling, the diagram carries the evidence*.

## The mock's findings (claude-design, run before this file)

The mock earned its restoration a second time. Four real faults, none of which
types, lint or 3,441 tests would have seen:

1. **The pinned instrument did not pin at all — silent killer #1.** The stage
   row carried `align-items:flex-start`, which cancels flex's default stretch,
   so the sticky column was 992px tall inside a 4,290px stage and scrolled
   away after the first chapter. Chapters drove nothing. **This is the same
   failure ⑳'s mock caught, arriving by a different cause.**
2. **Silent killer #2, and the nastier one: `overflow-x:hidden` on the page
   wrapper.** It computes `overflow-y:auto`, which makes the element a scroll
   container and breaks `position:sticky` against the viewport outright —
   measured, `top:-1843` instead of `0`. **Both killers go in the build as a
   named check, and into the traps list.**
3. **The drawing letterboxed inside its sheet** — a fixed `viewBox` aspect in
   a taller container left a quarter of the sheet as empty paper. Same family
   as ⑳'s viewport-tall void.
4. **The lay twin was a 232px thumbnail** — the smallest element on a sheet
   whose entire pitch is *drawing → what it becomes*. The meta-prompt's own
   rule says the twin "must track the instrument's state exactly" and is
   "never decoration"; a thumbnail beside a large plan gives the non-expert
   reader the smaller half. **Rebuilt as a full-width band.** This is the
   mock's most valuable finding and it changed the composition.
5. **Carried into the build as a rule:** the stage's bands must be
   **explicitly budgeted against 100vh**, not left to `flex-grow` — in the
   revised mock the interest calendar clipped off the bottom of the viewport.

## The instrument — Sheet 04, the spine of the page

**One clock: the calendar year, January → December, driven by scroll.**
Everything below reads off it, and nothing has a second timeline.

The stage pins and four chapters scroll past driving it (February, May, July,
October). Composition, top to bottom, inside one drawing sheet:

| Band | What it is | What the clock does to it |
|---|---|---|
| Title block | `ASPECT & FALL · SHEET 04 · PLANTING PLAN · 1:100` + three live readouts + the month | readouts recount every frame |
| **The plan** | plan-view drawing: house, terrace, hatched path, ten canopy circles at mature spread, leader labels, north arrow | beds take coloured-pencil fill; hue follows the season; a species in flower takes **its own** colour and lifts; the terrace's shade polygon deepens as the canopy leafs |
| **The twin** | full-width letterbox photograph of *the same corner* | cross-fades across four minted seasons |
| **The interest calendar** | species × 12 months; a bar per species; flowering bars in the plant's colour, structural interest in graphite | a **playhead line** tracks the month across the grid |

**Three readouts, all derived from the same model, none decorative:**
`IN FLOWER — n/19` · `CANOPY SHADE — n%` · `SUN LEAVES THE TERRACE — hh:mm`.

**Why this satisfies the lay-twin doctrine** (meta-prompt, ⑬ s60): the plan is
the expert instrument and the photograph is the lay twin, on one clock, at
equal weight — not the instrument with a picture appended. A visitor who
cannot read a plan still watches a garden go through a year; a visitor who can
read one gets the evidence underneath it.

## Casting — the checklist, run now and to be RE-RUN after any change of approach

- **Social-register dial: LOW-to-MID.** A garden design commission is not a
  social purchase; it is a considered, expensive, expert one. Per the
  price-register corollary this means **stillness over choreography** in the
  imagery, and **near-zero human presence** — one absorbed practitioner as the
  trust signal (the ⑯ roofer / ⑫ dentist model), never staff photos.
- **Lead archetype: ONE practitioner, absorbed, at the drawing board.** This
  vertical reads professional-serious (a paid expert producing documents) and
  §casting(7) leads male-and-experienced there — but it is equally a
  warmth/craft vertical. **Lead judgement call, one line to reverse: cast an
  experienced woman at the board.** Landscape design is a field where that
  reads entirely true, it is not the same casting as ⑳'s vet (different age,
  register and framing), and the trust signal here is the *drawing under her
  hands*, not the face. Recorded on NEEDS-STEVEN as a reversal.
- **Nature is the supporting cast — and here it is unusually literal.** The
  object is the DRAWING; nature is the thing the drawing becomes. That is the
  house style stated in the sharpest form the portfolio has had.
- **Dread to counter (§casting 8): not confinement — DISAPPOINTMENT.** The
  fear a garden client actually carries is *"I will spend a great deal and it
  will look like nothing for years, and not like the picture."* The page
  answers it head-on with the maturity chapter and the honest February
  chapter, rather than hiding it. **The honest answer is the differentiator.**
- **Printable-surface risk, composed OUT in advance rather than negated:** a
  drawing board is covered in flat printable surfaces — drawings with
  title blocks, scale rules, plan chests, rolled tubes, pencil barrels. Every
  one is a pseudo-text seed. **The frame to name: a close, high, over-the-
  shoulder crop of hands, a pencil and a partial drawing, cropped so no title
  block, ruler face or label is in frame.** Do not write "no text".
- **THE WINK (§casting 6), and it is hosted by the instrument:** at high
  summer only, a leader line appears on the plan pointing at the sunny end of
  the terrace, annotated **`CAT SITS HERE`** — a dry margin note in the
  drawing's own grammar, the kind a real designer actually pencils in. It is
  written into the copy as well so it survives no-JS. **Its host is the plan,
  which is the element least likely to change register — but if the plan is
  ever re-registered, this line is what gets re-homed, per ratchet 3.**

## Copy direction

Measured, dry, first-person-plural, and **unafraid of the unflattering fact**
— that is the register of someone who writes specifications. No adjective
stacking, no "bespoke", no "passion". The three load-bearing sentences are all
concessions: *"If a garden fails, it fails in February." · "Any planting looks
good in May — which is exactly why we do not design for it." · "Year one looks
thin. It is meant to."* A studio that says those things is more credible than
one that says it is award-winning.

## Honesty gates

- **Fictional business, disclosed** on the page footer and in `/guide`.
- **AI-generated imagery, disclosed** in `/guide`, with the model and credit
  cost per slot from the provenance manifests.
- **No invented awards, testimonials, client names or project counts.** "Two
  of us, twelve gardens a year" is a scale claim about a fictional studio and
  reads as one; there is no fake client list.
- **Countable claims checked against imagery** (§casting 3) before any keep.
- **The plant data must be real.** Every species named is a real plant and its
  flowering/interest months are its real ones. A landscape page that invents
  botany would fail the one test its own audience can run.

## Perf, reduced motion, no-JS

- **Reduced motion:** the clock freezes at high summer; the calendar shows the
  full year with no playhead; no cross-fades.
- **No-JS:** every chapter's text is in the markup, the plan renders at its
  summer state, the interest calendar renders complete (it is static SVG), and
  **the wink's line is in the copy** so it cannot be lost.
- Images sized, lazy-loaded below the fold, explicit dimensions — no CLS.
- Self-contained: no external hosts, fonts vendored (ratchet:
  `tests/template-portfolio.test.ts`).

### The one real risk on this page, named up front

**MINT 04–07 must be the same view four times.** Independent text-only mints
will produce four different gardens, which silently breaks the twin doctrine —
the twin would stop tracking the instrument and become decoration, which is
exactly the failure the doctrine exists to prevent.

Order of attack, decided now so it is not improvised at the vendor:

1. **Mint the summer frame first** (the best of the four to get right), then
   use an **image-EDIT seat** (nano-banana class — the seat that exists to
   modify an input image while holding composition) to move that same frame
   through the other three seasons. Editing is the correct tool: "same view,
   different season" is an edit, not a generation.
2. **Do NOT use soul-class reference-guided minting for this.** The s64 rule
   is explicit — the reference's caption wins over prompt text, so a ref is
   for *"make exactly this"*, never *"make this but different"*, and a season
   change is precisely "but different". The grey-soba take proves it.
3. **Fallback if the view will not hold: drop to TWO twin states** (winter and
   high summer) and let the plan carry the intermediate months, rather than
   ship four gardens pretending to be one. **A twin that lies is worse than a
   smaller twin.**
