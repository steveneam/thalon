Method note

How this page was made

Crateline is a fictional demonstration business. Every figure on the landing page — lanes, transit times, fleet counts, the on-time rate — is illustrative copy for a demo, not a real service. All imagery is AI-generated.

Design

The build started with a look-first study of logistics landing pages, brutalist web design and cargo stencil typography. The genre default for freight sites — ocean-vessel photography, navy/teal, generic supply-chain copy, dashboard screenshots — was deliberately refused. Instead the page borrows freight's own paperwork: the layout reads as a shipping manifest (ruled ledgers, a waybill, a container data panel), set in a clean stencil face beside a data mono, on bone paper with container safety-orange as the one loud colour. Motion is limited to what a depot does: stamps thunk in, counters tick, the status board changes. The structure never animates.

Type: Saira Stencil One, Archivo and IBM Plex Mono — all SIL Open Font License, vendored locally with their licenses. The page is a single self-contained file: no frameworks, no CDNs, no external requests, with reduced-motion and no-JS fallbacks.

Iteration passes

  • Pass 1 (fault-hunt): section numbering regularised (01–04); hero copy regrouped so the headline+lede and the waybill anchor the column; trackline stamp/wire animation verified live; favicon added to clear the only 404.
  • Pass 2 (ambition-push): cursor floodlight over the hero yard (fine pointers only), depot ticker between hero and lanes, live-cycling waybill status, counters on the capacity panel, stamp-in sequence on the tracking line.
  • Pass 3 (fault-hunt): 390 px pass — no horizontal overflow, ledger scrolls in its own container, sticky header verified; reduced-motion audit (all animation gated, stamps and wire render static); no-JS audit (everything visible, ticker static).
